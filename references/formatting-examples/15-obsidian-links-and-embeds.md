# Obsidian Links and Embeds

**Purpose:** Use Obsidian-specific navigation and transclusion when portability
is not required for that view.

**Portability:** Platform-specific.

## Wikilink

```markdown
[[markdown-protocol/SKILL|Markdown Protocol]]
```

Portable default:

```markdown
[Topic name](topic-name.md)
```

## Embed

```markdown
![[markdown-protocol/references/core-protocol#In brief]]
```

An embed can show authoritative content in another note without copying it,
but viewers outside Obsidian may display only the source syntax.

## Avoid

Do not make an Obsidian embed the only route to essential information. Do not
mix link styles unpredictably within one collection.

## Fallback

Use a normal relative link and a one-sentence summary.
