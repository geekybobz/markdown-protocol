# Headings and Sections

**Purpose:** Give a document a readable hierarchy and navigable outline.

**Portability:** Core.

## Source

```markdown
# Document title

## Main idea

### Supporting detail
```

## Result

`#` is the document title, `##` begins a principal section, and `###` belongs
inside that section. Use one `#` heading per file and avoid skipping levels.

## Avoid

Do not use headings merely to make text larger. A heading should name a real
section that a reader might navigate to.

## Related formatting

Use `**bold**` for limited emphasis, `*italic*` when introducing a term, and
`---` for a thematic break only when a heading would be unnecessary.
