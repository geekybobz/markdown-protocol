# Tables

**Purpose:** Compare repeated fields across several items.

**Portability:** Common.

## Source

```markdown
| State | Meaning | Next action |
|---|---|---|
| Draft | Still changing | Continue writing |
| Review | Ready to inspect | Check accuracy |
| Stable | Suitable for use | Maintain narrowly |
```

## Result

Each row describes one state using the same three fields.

## Avoid

Do not place long paragraphs, large code blocks, or deeply nested information
inside a table. A list or separate sections will be easier to edit on narrow
screens.

## Fallback

Use one heading or bullet per item followed by its fields.
