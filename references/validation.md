# Validation

Validate the exact changed collection in proportion to its complexity.

## Structure

- The implemented change matches the reviewed proposal.
- Material expansion received renewed review before implementation.
- An identifiable Front Door exists.
- The chosen profile is no larger than necessary.
- Maps route by intention and indexes list inventory.
- Topics are reachable and meaningful independently.
- Short supporting material has not been fragmented into orphan files.

## Content ownership

- Every important fact has one authoritative owner.
- Outer summaries agree with their topic owners.
- Generated views contain no manually maintained canonical fact.
- Assumptions, limitations, and uncertainty remain visible.

## Links

- Relative links resolve from their source files.
- Section anchors exist.
- Parent and return links are useful rather than ceremonial.
- Every authored page ends with a resolving Home footer link.
- Previous and Next links match the declared reading order and resolve when
  present; first and last pages omit unavailable directions.
- Platform-specific links have a portable route or fallback.

## Formatting

- Heading levels form a coherent hierarchy.
- Lists express collections and numbered lists express order.
- Tables remain compact enough to scan.
- Collapsed content is optional, not required for correctness.
- Code blocks declare a useful language when applicable.
- Tool-specific syntax is identified honestly.

## Visuals

- Each visual answers a defined question.
- Large graphs are decomposed when that improves readability.
- Essential meaning is repeated as text or a compact mapping.
- Mermaid or other source renders in every claimed target environment.
- Static exports retain an editable source.

## Mathematics

Do not claim that `$...$`, `$$...$$`, `\(...\)`, or `\[...\]` renders until
the exact syntax has been tested in the intended application. Record the
application and result when the later renderer investigation is performed.

## Human and model checks

A human should be able to understand the purpose, navigate without knowing the
directory tree, and edit ordinary content without advanced tooling. A model
should be able to orient from the entry, load only relevant topics, distinguish
authored from generated content, and follow explicit links without scanning
the whole repository.

## Completion evidence

Report which files changed, which links and renderers were checked, which
generated views were rebuilt, and which optional features remain unverified.
Also state whether the work stayed inside the approved design or required a
reviewed expansion.
