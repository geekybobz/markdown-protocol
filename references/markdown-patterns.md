# Markdown Pattern Gallery

This is the catalogue for formatting techniques. Open only the linked example
needed for the current task.

## Portability levels

| level | meaning |
|---|---|
| Core | ordinary Markdown with strong cross-renderer support |
| Common | widely supported extension; verify the intended renderer |
| Render-dependent | requires a diagram, mathematics, or HTML-capable renderer |
| Platform-specific | requires a named application such as Obsidian |

## Pattern contract

Each example explains its purpose, portability, use and avoidance conditions,
source syntax, expected result, fallback, and maintenance risk.
